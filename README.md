# ProofAgent AI 🤖💼
### Autonomous Web3 Campaign Engine
**Built for NEAR Hackathon 2026** | *Track 04: Autonomous Business* & *Track 07: Agent Economy*

ProofAgent AI is an enterprise-grade, zero-ops marketing engine that transforms raw technical data (commits, documentation, transcripts) into fully optimized, cryptographically verified social media campaigns. Driven by a 4-node autonomous sub-agent network and powered by NEAR Protocol intents, ProofAgent AI eliminates the manual bottleneck of developer marketing while introducing absolute deterministic accountability on-chain.

## 🚀 Core Architecture & Pipeline
The engine orchestrates four specialized sub-agents running asynchronously to process content and settle micro-payouts natively on the NEAR Testnet.

```text
[ Ingest Node ] ➔ [ Semantic Parser ] ➔ [ Thread Synthesizer ] ➔ [ Intent Relayer ]
(Raw Data)       (Entity/Proof Hook)      (X/Twitter Drafts)      (NEAR Payout & Anchor)
```

1. **Ingestion Node (Multi-Source Aggregator):** Consumes unstructured, multi-format technical streams including GitHub commit logs, video transcripts, and Markdown documentation.
2. **NLP Semantic Parser (Entity & Proof Tagging):** Extracts structural entities and establishes cryptographic context hooks, mapping code modifications directly to marketing intent.
3. **X Thread Synthesizer (Campaign Generation):** Crafts highly engaging multi-tweet campaigns structured for maximum reach, optimized automatically based on the ingested material.
4. **NEAR Intent Relayer (Settlement & Verification):** Dispatches cryptographically signed micro-payouts to contributors via NEAR Intents and anchors a verifiable hash of the operation to a NEAR block.

## 💡 Key Innovations

### 1. Intent-Driven Autonomous Economics (Track 07)
Unlike traditional agent setups that require manual transaction signing, ProofAgent AI leverages **NEAR Intents**. The sub-agents express *what* state they want to achieve (e.g., *"Settle a 1.22 NEAR reward to adexberry.near upon verifiable proof of campaign generation"*). This allows for fluid, decentralized execution, cross-chain flexibility, and ultra-low friction automated business management.

### 2. Verifiable Decision-Making (Track 04)
Every single campaign synthesis is anchored directly to a NEAR block (e.g., Block `#148,392,133`). By logging the state hash and payload cryptographic proof on-chain, ProofAgent AI completely eliminates "AI hallucination accountability" issues. Businesses can audit exactly what their autonomous marketing nodes did, when they did it, and what it cost.
